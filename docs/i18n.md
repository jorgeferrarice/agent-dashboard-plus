# Interface language

The dashboard speaks **Portuguese (Brazil)** and **English**.
Portuguese is the default.

## Changing the language

Open the settings cog (⚙) at the right end of the tab bar and pick
a language under **Language / Idioma**. The page switches at once,
without reloading. The choice is saved with your account, so it
follows you to every browser and device you sign in from; dates and
numbers are shown the way that language writes them.

## For developers

All interface text lives in `frontend/src/i18n/messages/`, one file
per area of the interface (`core.ts` for the tab bar and dashboard
header, `dashboard.ts`, `terminal.ts`, `tasks.ts`), merged by
`frontend/src/i18n/messages.ts`. In each file the English
dictionary (`<area>En`) defines the keys and the Portuguese one
(`<area>Pt`) must have every one of them — TypeScript refuses to
build when one is missing, and a test checks that both languages
have the same keys and the same `{placeholders}`.

In a component:

```tsx
import { useI18n } from '../i18n';

const { t, language } = useI18n();
t('tabs.close', { label }); // "Fechar aba bash" / "Close tab bash"
new Date(iso).toLocaleDateString(language); // dates in the chosen language
```

To add text, add a key to the English dictionary of its area and
its translation to the Portuguese one, then use `t('your.key')`.
Lists of labels (columns, priorities, ...) hold message keys, not
text, and are translated where they are shown.

Error messages from the backend are shown in the chosen language
when they are one of the backend's fixed messages (see
`DETAIL_KEYS` in `frontend/src/tasksApi.ts`); messages that come
from a tracker (Jira, Shortcut, Huly) are shown as the tracker
wrote them. Keep keys grouped by screen (`tabs.*`,
`dashboard.*`, `tasks.*`, ...).

Where things are kept:

- `I18nProvider` (wrapping the app in `main.tsx`) holds the language.
  It starts with the copy this browser saved (localStorage key
  `agentDashboard.language`), then takes the one saved on the
  server, and sets `<html lang>`.
- The server keeps it per user (by login email) in the
  `user_prefs` table: `GET /me/preferences` and
  `PUT /me/preferences` with `{"language": "pt-BR" | "en"}`.
- Without a provider (unit tests, a component rendered alone),
  `useI18n()` gives English.
